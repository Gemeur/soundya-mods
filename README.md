# Soundya Mods — Каталог модов для Яндекс Станции

Официальный репозиторий каталога модов и плагинов для кастомной прошивки **Soundya**.

🌐 **Сайт каталога (GitHub Pages):** [https://gemeur.github.io/soundya-mods/](https://gemeur.github.io/soundya-mods/)

## ⚡ Как установить мод на Станцию

1. Скачайте `.zip` архив нужного мода со страницы [каталога](https://gemeur.github.io/soundya-mods/) или из папки `mods/<название>/<название>.zip`.
2. Откройте в браузере панель управления колонкой: `http://<IP-колонки>:8080/`.
3. Перейдите во вкладку **«Моды»**.
4. Нажмите **«+ Загрузить пакет мода»** или перетащите `.zip` архив мышкой в окно браузера.
5. Мод активируется мгновенно без перезагрузки всей колонки!

## ➕ Как добавить свой мод в каталог

Каталог автоматически сканирует репозиторий через GitHub API. Чтобы добавить новый мод:
1. Создайте в репозитории папку `mods/<id-мода>/`.
2. Положите в неё:
   - `<id-мода>.zip` — архив с файлами мода (`manifest.json`, `.js`, `.css`, `backend`).
   - `README.md` — описание с метаданными.
3. Оформите `README.md` по шаблону:

```markdown
# Название мода

> **Устройство:** Станция 2 (или Все Станции)
> **Категория:** Подсветка (или ТВ и Умный дом / Звук)
> **Работает с:** 88-LED матрица / Android TV / Home Assistant
> **Версия:** v1.0.0
> **Совместимость:** Soundya OS >= 0.5.5

Краткое описание мода (1-2 предложения, пойдет в карточку на сайте).

### Возможности
- Пункт 1
- Пункт 2

### Установка
Инструкция по установке...
```

4. Отправьте Pull Request — после объединения мод появится в каталоге автоматически!
