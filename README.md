# soundya-mods

Каталог и репозиторий модов для кастомной прошивки Soundya.

Веб-версия каталога: https://gemeur.github.io/soundya-mods/

---

## Архитектура

Репозиторий является реестром дополнений и источником статических файлов. Веб-интерфейс каталога развернут на GitHub Pages, считывает директорию `mods/` и автоматически формирует карточки дополнений на основе метаданных из файлов `README.md`.

### Структура репозитория

```
soundya-mods/
├── index.html              # Веб-каталог с поиском и фильтрацией
├── README.md               # Документация репозитория
└── mods/
    └── <mod-id>/           # Директория мода (идентификатор в kebab-case)
        ├── <mod-id>.zip    # Пакет установки для прошивки Soundya
        └── README.md       # Описание и метаданные для каталога
```

---

## Структура пакета мода (.zip)

Архив мода устанавливается через панель управления Soundya и может содержать следующие компоненты:

- `manifest.json` — конфигурационный файл с метаданными мода (id, название, версия);
- `<mod-id>.js` — скрипт интерфейса для интеграции в веб-панель Soundya;
- `<mod-id>.css` — стили пользовательского интерфейса (опционально);
- `<mod-id>-backend` — бинарный файл сервиса (опционально, для фоновых демонов);
- `README.md` — встроенное описание мода.

---

## Спецификация README.md для каталога

Для корректной обработки парсером каталога и работы фильтров файл `mods/<mod-id>/README.md` должен содержать блок метаданных в начале документа:

```markdown
# Название мода

> **Устройство:** Станция 2
> **Категория:** Подсветка
> **Работает с:** Название совместимого сервиса или протокола
> **Версия:** v1.0.0
> **Совместимость:** Soundya OS >= 0.5.5

Краткое описание назначения мода (один абзац). Этот текст выводится на карточке в каталоге.

### Возможности
- Функция 1
- Функция 2

### Установка
Инструкция по установке и настройке параметров.
```

### Поддерживаемые категории
- Подсветка
- ТВ и Умный дом
- Звук

## Установка модов на устройство

1. Скачайте архив `<mod-id>.zip` со страницы каталога.
2. Откройте веб-панель Soundya в браузере: `http://<IP-адрес-колонки>:8080/`.
3. Перейдите в раздел «Моды».
4. Загрузите архив через кнопку добавления пакета или перетаскиванием файла.
5. Мод регистрируется в системе сразу после загрузки.

---

## Добавление мода в каталог

1. Создайте подпапку `mods/<mod-id>/`.
2. Поместите подготовленный архив `<mod-id>.zip` и файл `README.md`.
3. Убедитесь в отсутствии временных файлов компиляции в архиве.
4. Отправьте Pull Request в ветку `main`.
