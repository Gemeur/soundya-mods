# TV Voice

> **Устройство:** Все Станции
> **Категория:** Интеграции
> **Работает с:** Android TV, Google TV, Projectivy Launcher, ADB
> **Версия:** v1.0.0
> **Совместимость:** Android TV 9+, Soundya OS >= 0.5.5

Голосовое управление телевизорами и проекторами на базе Android TV по локальной сети через протокол ADB.

## Архитектура

Модуль работает напрямую по сети Wi-Fi/Ethernet через протокол Android Debug Bridge (порт 5555). Не требует установки сторонних приложений на телевизор и наличия root-прав.

Интегрируется с системным сервисом распознавания речи Soundya, перехватывая целевые голосовые команды управления медиа и приложениями.

## Возможности

- Прямое сетевое подключение к Android TV / Google TV по IP-адресу.
- Голосовой запуск установленных приложений: YouTube, SmartTube, Кинопоиск, Lampa, NUM, VLC.
- Голосовой ввод текста в активные поля поиска на экране ТВ.
- Эмуляция стандартных кнопок пульта ДУ: громкость, пауза, воспроизведение, навигация, выключение.
- Глубокая интеграция с альтернативным лаунчером Projectivy Launcher.

## Установка и настройка

1. На телевизоре перейдите в «Настройки устройства» -> «Для разработчиков» и включите пункт «Отладка по сети» (Network Debugging).
2. Зафиксируйте локальный IP-адрес телевизора в настройках роутера.
3. Скачайте `tv-voice.zip` и загрузите во вкладке «Моды» веб-панели колонки.
4. В появившемся блоке настроек мода введите IP-адрес телевизора и нажмите «Подключить».
