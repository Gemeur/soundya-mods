# Управление ТВ и проектором (TV Voice)

> **Устройство:** Все Станции
> **Категория:** ТВ и Умный дом
> **Работает с:** Android TV, Google TV, Projectivy Launcher, ADB
> **Версия:** v1.0.0
> **Совместимость:** Android TV 9+, Soundya OS >= 0.5.5

Голосовое управление Android TV и проекторами через Яндекс Станцию по локальной сети без рут-прав.

### Возможности
- Прямое управление через ADB по Wi-Fi
- Голосовой запуск приложений (YouTube, Lampa, Кинопоиск, NUM, SmartTube)
- Ввод текста на экране телевизора голосом («Алиса, введи интерстеллар на ТВ»)
- Интеграция с популярным лаунчером Projectivy
- Эмуляция кнопок пульта ДУ (пауза, воспроизведение, громкость, навигация)

### Установка
1. Включите «Отладку по сети» (Network Debugging / ADB) на вашем телевизоре или проекторе.
2. Скачайте `tv-voice.zip` и загрузите во вкладку «Моды» на колонке.
3. В настройках мода укажите IP-адрес телевизора.
