# Мониторинг системы

> **Устройство:** Все Станции
> **Категория:** Утилиты
> **Работает с:** /proc, /sys/class/thermal, WebUI
> **Версия:** v1.0.0
> **Совместимость:** Soundya OS >= 0.5.5

Модуль мониторинга аппаратных ресурсов колонки в реальном времени: температура процессора, загрузка ядер, оперативная память, свободное место на накопителе и список активных процессов.

## Архитектура

Модуль состоит из двух компонентов:
- Клиентская часть (`sysmon.js`, `sysmon.css`) — встраивает компактный индикатор в шапку веб-интерфейса Soundya и предоставляет подробную панель системной телеметрии.
- Фоновый сервис (`sysmon-backend`) — легковесный системный бинарный сервис на Rust, считывающий показатели ядра Linux через псевдофайловую систему `/proc` и `/sys` без создания фоновой нагрузки.

## Возможности

- Отображение текущей температуры CPU с цветовой индикацией безопасного температурного диапазона.
- Мониторинг суммарной загрузки процессора и Top-5 наиболее ресурсоёмких процессов (Алиса, аудиотракт, системные демоны).
- Расход оперативной памяти (RAM) с детализацией занятого и доступного объема.
- Мониторинг дискового пространства раздела `/data` для контроля свободного места под моды и кэш.
- Отображение времени непрерывной работы устройства (Uptime).
- Предоставление JSON API по маршрутам `/api/sysmon` и `/api/system/stats` для интеграции со внешними системами мониторинга.

## Установка

1. Скачайте архив `sysmon.zip`.
2. В веб-интерфейсе колонки перейдите во вкладку «Моды».
3. Загрузите архив через форму загрузки пакета.
4. Мод и фоновый сервис телеметрии активируются автоматически.
