# Плавающий плеер внизу

> **Устройство:** Все Станции
> **Категория:** Медиа
> **Работает с:** WebUI, Mobile, Tablet, Desktop, SoundCloud
> **Версия:** v1.0.0
> **Совместимость:** Soundya OS >= 0.5.5

Фиксированный плавающий плеер внизу экрана в стиле Glassmorphism с улучшенным плавным поиском треков, очередью воспроизведения и всеми функциями управления.

## Возможности
- **100% сохранение всех функций:** Включает в себя абсолютно все элементы оригинального плеера Soundya:
  - Обложка трека с кнопкой перехода на SoundCloud
  - Название трека и артист
  - Лайк текущего трека (♡ / ♥)
  - Воспроизведение, пауза, предыдущий, следующий трек, кнопка полного закрытия
  - Перемешивание (Shuffle) и повтор (Repeat)
  - Интерактивный прогресс-бар перемотки с таймкодами (позиция и длительность)
  - Кнопка поиска с обновленным выпадающим меню
  - Добавление трека в плейлист
  - Включение похожих треков
  - Всплывающее окно очереди треков (Queue) с автоскроллом к текущему
  - Всплывающее окно громкости со слайдером и выбором вывода звука (Колонка / Bluetooth / Браузер)
  - Кнопка закрытия плеера с компактной плавающей пилюлей восстановления
- **Улучшенный поиск треков:**
  - Красивая стеклянная шторка Dropup, плавно открывающаяся над баром
  - Иконка поиска и кнопка быстрой очистки поля (✕)
  - Плавная анимация результатов поиска и карточек треков
  - Закрытие по клику вне области или по клавише Escape
- **Адаптивность:**
  - Полная поддержка настольных мониторов с учетом левого бокового меню (Sidebar)
  - Полная оптимизация для мобильных устройств и смартфонов (двухрядный компактный вид)
  - Автоматический отступ страницы снизу (`padding-bottom`), чтобы контент вкладок не перекрывался

## Установка
1. Скачайте архив `dock-player.zip`.
2. В веб-интерфейсе колонки перейдите во вкладку «Моды».
3. Загрузите архив через форму добавления пакета.
