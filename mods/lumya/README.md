# Lumya

> **Устройство:** Станция 2
> **Категория:** Интерфейс
> **Работает с:** 88-LED адресная матрица, ALSA loopback, WebUI
> **Версия:** v1.0.0
> **Совместимость:** Soundya OS >= 0.5.5

Модуль управления аппаратной 88-LED матрицей Яндекс Станции 2. Включает автономный бэкенд светомузыки с минимальной задержкой, библиотеку из 34 эффектов и живое веб-зеркало.

## Архитектура

Модуль состоит из двух компонентов:
- Клиентская часть (`lumya.js`, `lumya.css`) — встраивается в веб-интерфейс колонки, обеспечивает выбор эффектов, настройку палитр, таймеров и отображение эмулятора матрицы на Canvas.
- Фоновый сервис (`lumya-backend`) — системный бинарный сервис на Rust, считывающий аудиопоток напрямую из ALSA loopback устройства без нагрузки на CPU и управляющий светодиодами по SPI/I2C.

## Возможности

- 88 индивидуально адресуемых RGB светодиодов матрицы.
- Аппаратная светомузыка на базе БПФ (FFT) с минимальной задержкой.
- 34 встроенных эффекта: статические градиенты, динамические волны и светомузыкальные пресеты.
- 12 цветовых палитр: Северное сияние, Закат, Неон, Океан, Киберпанк, Огонь и др.
- Ночной режим с автоматическим ограничением максимальной яркости.
- Режим «Уступать Алисе»: временное отключение анимации при голосовой активности ассистента.
- Живое зеркало матрицы в браузере с частотой обновления 60 кадров/сек.

## Установка

1. Скачайте архив `lumya.zip`.
2. В веб-интерфейсе колонки перейдите во вкладку «Моды».
3. Загрузите архив через форму загрузки пакета.
4. Мод и фоновый сервис подсветки активируются автоматически.
