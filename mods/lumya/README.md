# Lumya (Подсветка матрицы)

> **Устройство:** Станция 2
> **Категория:** Подсветка
> **Работает с:** 88-LED матрица, локальный WebUI
> **Версия:** v1.0.0
> **Совместимость:** Soundya OS >= 0.5.5

Полноценное управление 88-LED адресной матрицей Яндекс Станции 2 для кастомной прошивки Soundya.

### Возможности
- 88 индивидуально адресуемых RGB светодиодов
- Аппаратная светомузыка с минимальной задержкой обработки звука (ALSA loopback)
- 34 встроенных динамических эффекта (плавные градиенты и светомузыка)
- 12 цветовых палитр (Северное сияние, Закат, Океан, Киберпанк, Огонь и др.)
- Ночной режим с ограничением максимальной яркости
- Живое зеркало матрицы в браузере (60 FPS)

### Установка
1. Скачайте архив `lumya.zip`.
2. В веб-интерфейсе колонки (`http://<IP-колонки>:8080`) перейдите в раздел «Моды».
3. Загрузите архив через кнопку «+ Загрузить пакет мода» или перетащите мышкой.
