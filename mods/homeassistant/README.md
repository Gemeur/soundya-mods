# Home Assistant

> **Устройство:** Все Станции
> **Категория:** Интеграции
> **Работает с:** Home Assistant (HACS), 88-LED матрица, медиаплеер
> **Версия:** v1.0.0
> **Совместимость:** Home Assistant >= 2024.1, Soundya OS >= 0.5.5

Двусторонняя локальная интеграция Яндекс Станции с сервером Home Assistant без использования сторонних облачных сервисов и MQTT.

## Архитектура

Интеграция состоит из двух частей:
- Мод для колонки (`homeassistant.zip`) — добавляет в веб-панель Soundya блок настроек и генерацию ссылки для быстрой установки в HACS.
- Кастомная интеграция Home Assistant (`soundya-ha`) — компонент для HA, опрашивающий локальный REST API колонки (порт 8080) и предоставляющий сущности медиаплеера, света, сенсоров и переключателей.

## Предоставляемые сущности

- `media_player.station_2` — управление воспроизведением, громкостью, обложки треков, поддержка вызова службы `media_player.play_media`.
- `light.station_2_matrix` — управление 88-LED матрицей (яркость, RGB-палитра, переключение 34 встроенных эффектов).
- `sensor.station_2_last_heard` — текст последней распознанной Алисой фразы. Позволяет использовать голосовые фразы в комнате как триггеры любых автоматизаций Home Assistant.
- `sensor.station_2_wifi_signal`, `_ping`, `_cpu_temperature` — мониторинг параметров устройства.
- `switch.station_2_yield_alice` — переключатель приоритета микрофона Алисы.
- `switch.station_2_night_mode` — ночной режим подсветки.
- `button.station_2_like`, `_unlike` — оценка текущего трека в Яндекс Музыке.

## Установка

1. Скачайте `homeassistant.zip` и загрузите во вкладку «Моды» на колонке.
2. В веб-панели колонки перейдите в «Настройки» -> «Устройства» -> карточка «Home Assistant».
3. Нажмите кнопку добавления репозитория в HACS либо добавьте URL репозитория интеграции вручную в HACS как Custom repository.
4. В Home Assistant добавьте интеграцию Soundya и укажите локальный IP-адрес колонки.
