# Home Assistant Интеграция

> **Устройство:** Все Станции
> **Категория:** ТВ и Умный дом
> **Работает с:** Home Assistant (HACS), 88-LED матрица, медиаплеер
> **Версия:** v1.0.0
> **Совместимость:** Home Assistant >= 2024.1, Soundya OS >= 0.5.5

Нативная интеграция прошивки Soundya и подсветки Lumya с Home Assistant напрямую по локальной сети без MQTT.

### Возможности
- **Медиаплеер:** отображение треков, обложек, громкость, пауза/плей, поддержка `play_media` в сценариях
- **Управление светом:** 88-LED матрица Станции 2 (яркость, RGB-цвет, выбор 34 эффектов матрицы)
- **Сенсор услышанных фраз:** `sensor.station_2_last_heard` — запуск сценариев Home Assistant по фразам Алисе!
- **Сенсоры телеметрии:** Wi-Fi сигнал, пинг сети, температура процессора
- **Переключатели:** режим «Уступать Алисе», ночной режим подсветки, эквалайзер, обход блокировок (zapret)
- **Кнопки:** лайк/дизлайк текущего трека Яндекс Музыки
- **Быстрая установка:** поддержка установки через HACS в 1 клик

### Установка
1. Скачайте `homeassistant.zip` и загрузите во вкладку «Моды» в веб-интерфейсе колонки.
2. В веб-интерфейсе колонки перейдите в «Настройки» → «Устройства» → карточка «Home Assistant».
3. Нажмите кнопку «Добавить в Home Assistant (HACS)» или вручную добавьте репозиторий `https://github.com/Gemeur/soundya-ha` в HACS.
